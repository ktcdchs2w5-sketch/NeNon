NENON — стартовый макет Mini App

Что внутри:
- index.html — структура экранов
- style.css — оформление в бело-чёрном стиле
- app.js — переключение экранов и демонстрация поиска

Важно:
Это только интерактивный дизайн-прототип. Здесь пока НЕТ реальных пользователей,
анонимной доставки сообщений, аккаунтов, сервера или голосовых звонков.
Кнопка поиска имитирует процесс, но никого не подключает.

Как посмотреть с телефона:
1. Распакуй архив в файловом менеджере, если телефон это поддерживает.
2. Открой index.html в браузере.
Если браузер не открывает локальные HTML-файлы, понадобится разместить эти файлы
на статическом хостинге. Следующим шагом я помогу сделать это с телефона.

Дальше:

2. Подключим Telegram Mini App.

4. Добавим серверную часть для текстовых чатов.
5. Отдельно разработаем голосовые соединения WebRTC.
